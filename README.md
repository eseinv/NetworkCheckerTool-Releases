# Network Checker downloads

Network Checker is a compact Windows x64 widget for monitoring configured network devices.

1. Open the [latest release](https://github.com/eseinv/NetworkCheckerTool-Releases/releases/latest).
2. Download and fully extract the Portable ZIP into a writable folder.
3. Close any older copy and run the launcher at the top of the extracted folder.

Existing devices, settings and logs are kept in the current user's Local AppData.
From the portable build, open **Config > Check for updates** to install later releases in place.
The included certificate is self-signed and is intended only for controlled PCs whose owners recognize the publisher.

This repository contains compiled releases and signed update metadata.
